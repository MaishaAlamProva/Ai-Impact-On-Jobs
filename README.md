## Project Overview: AI Impact on Job Displacement

This project uses Machine Learning techniques to analyze the risk of job displacement caused by AI across different industries. The notebook explores how automation and industry-specific factors influence employment trends.

### Key Features
- Data analysis on AI-driven work automation and job displacement trends.
- Machine Learning models including Logistic Regression, Random Forest, and SVM for displacement risk prediction.
- Explainable AI (XAI) using SHAP and LIME to identify the most influential prediction factors.
- Data visualizations created with Matplotlib and Seaborn for clear insight representation.
